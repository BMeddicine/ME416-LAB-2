# Camera calibration

| File | Camera | Status |
|---|---|---|
| `webcamParams.mat`, `webcamParamsScript.m` | USB webcam, 640×480, mounted over the plate | **Used for the final runs.** Mean reprojection error 0.11 px (the figure used in the report's error budget). The Python tools pass it to MATLAB as `--calibration` (the default), and it is also `calibrationFile` in `config/layout.json` |
| `iphone-0.5-cameraparams.mat`, `Camera_Calibration_Iphone.m` | iPhone 17 Pro, 0.5x lens, 5712×4284 | First plan, not used in the end. Mean reprojection error 0.31 px. The calibration photos were removed from the repo (still in git history), so the script's image paths no longer resolve |

Both `.m` scripts were generated by MATLAB's Camera Calibrator app. A calibration is only valid for the exact camera and resolution it was made with, and the vision code refuses a photo of any other size.
