# Config

- **One file per arm** (Bryson's, Aviva's): servo fit (a, b) per joint, fit residual, backlash, joint limits, the name it spells. This is the only thing that changes between the two runs.
- **One shared layout file**: tag IDs, measured tag size, tag-to-disc offset, heights (disc, ink pad, paper), tool lengths, stamp holder positions (OnShape or tags; justify in report), press radius and letter spacing.
